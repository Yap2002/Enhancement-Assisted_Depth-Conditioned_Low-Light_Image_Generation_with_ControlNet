# Dissertation figures

This directory contains the 16 image files used in the final dissertation PDF.
The filenames follow the figure numbering in Chapters 1--5.

## Contents

- Chapter 1: Figures 1.1--1.2
- Chapter 2: Figures 2.1--2.5
- Chapter 3: Figure 3.1
- Chapter 4: Figures 4.1--4.3
- Chapter 5: Figures 5.1--5.5

The rendered PNG and JPEG files are stored in `figures/` so that the dissertation
assets can be viewed directly on GitHub and reused by the LaTeX project. Some
composite figures include selected examples from ExDark. Their inclusion does not
change the ownership or licence of the source dataset; see `../DATA_LICENSE.md`.
